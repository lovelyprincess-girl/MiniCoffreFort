# 🔒 Mini Coffre-Fort Chiffré

## 📖 Description

Mini Coffre-Fort Chiffré est un projet réalisé en Python dans le cadre de mon apprentissage du développement Python et de ma préparation au Bachelor 3 en cybersécurité.

Cette application permet de stocker des fichiers de manière sécurisée grâce au chiffrement. Elle utilise une clé de chiffrement pour protéger le contenu des fichiers et un mot de passe pour contrôler l'accès au coffre-fort.

---

## 🎯 Objectifs du projet

* Découvrir la manipulation de fichiers en Python.
* Comprendre le fonctionnement du chiffrement.
* Organiser un projet en plusieurs modules.
* Mettre en pratique les notions apprises pendant ma formation Python.
* Réaliser un premier projet orienté cybersécurité.

---

## 🛠️ Fonctionnalités

* Ajouter un fichier.
* Lister les fichiers enregistrés.
* Lire un fichier.
* Supprimer un fichier.
* Chiffrer automatiquement les données.
* Déchiffrer automatiquement les données.
* Protéger l'accès avec un mot de passe.
* Verrouiller le coffre après trois tentatives incorrectes.
* Enregistrer les accès dans un fichier de logs.
